몽글 개인정보처리방침

시행일: 2026년 9월 21일

몽글 - AI 음성 메모·노트·할 일(이하 “몽글”)은 음성을 노트와 할 일로 정리하는 Android 앱입니다. 몽글 계정 없이 사용할 수 있으며 기본은 기기 안에서 음성을 인식하고 글을 정리하는 방식입니다. 사용자가 로그인한 계정의 Mongle Plus 클라우드 처리를 선택하면 해당 녹음과 전사문을 외부 AI 서비스로 전송합니다. 로컬 기능은 계정과 구독 없이 사용할 수 있습니다. 이 방침은 앱이 처리하는 정보, 외부 통신, 보관 기간과 사용자가 정보를 관리하는 방법을 설명합니다.

1. 앱이 기기에서 처리하는 정보

사용자가 기능을 선택하면 몽글은 다음 정보를 기기 안에서 처리합니다.

  • 마이크로 녹음한 음성
  • 음성에서 만든 전사문, 제목, 요약, 카테고리와 할 일
  • 사용자가 직접 작성하거나 수정한 노트, 할 일, 일정과 자주 쓰는 말
  • 알림, 모델 선택, Wi-Fi 전용 다운로드 등 앱 환경설정
  • 로컬 또는 Plus 처리 방식 선택 등 앱 환경설정

로컬 AI 처리는 녹음·전사문·노트·할 일을 AI 서비스로 전송하지 않습니다. 별도로 암호화 동기화를 켜면 아래 설명에 따라 암호화한 기록 사본을 서버에 보관합니다. 앱은 개인 AI 공급자 API 키를 입력받거나 저장하지 않습니다. Plus는 아래 설명에 따라 Google 계정 로그인과 서버를 통한 클라우드 처리를 이용합니다. 광고, 분석 SDK 또는 원격 충돌 보고 기능은 없습니다.

2. AI 모델 다운로드와 외부 통신

사용자가 AI 모델 다운로드를 시작하면 몽글은 HTTPS를 통해 Hugging Face에서 음성 인식과 글 정리에 사용할 여러 AI 모델 파일을 받습니다. 음성, 전사문, 노트, 할 일은 이 요청에 포함하지 않습니다.

인터넷 통신의 특성상 모델 파일 제공자인 Hugging Face는 IP 주소, 요청 시각과 일반적인 네트워크·기기 정보를 받을 수 있습니다. Hugging Face는 서비스 사용 과정에서 IP 주소, 위치, 기기 유형·모델·운영체제 등의 정보를 자동 기록할 수 있다고 안내합니다. 해당 정보의 처리는 Hugging Face 개인정보처리방침을 따릅니다. 모델 다운로드를 건너뛰어도 직접 노트와 할 일을 작성할 수 있습니다.

선택형 Mongle Plus

Plus를 선택하면 Google 로그인으로 확인한 계정 식별자, 이메일과 표시 이름을 Plus 서버에서 처리합니다. Google Play가 구독 결제를 처리하며 몽글은 결제 카드 정보를 받지 않습니다. 서버는 암호화된 구매 토큰과 구독 상태·만료 시각을 보관하고 Google Play를 통해 사용 권한을 확인합니다. 로그인 세션은 30일 후 만료되며 서버에는 세션 토큰의 해시만 보관합니다.

클라우드를 선택하면 이후 새 기록의 기본 처리 방식이 됩니다. 클라우드 방식으로 처리하는 음성·전사문·분류 목록과 처리 언어 등 필요한 정보를 HTTPS로 몽글 Plus 서버, OpenRouter 및 실제 모델 제공업체에 전송합니다. 기존 로컬 기록은 AI 처리를 위해 자동 전송하지 않습니다. 자연어 검색의 클라우드 답변은 별도 전송 확인 후 검색어와 관련 기록의 제목·발췌문을 전송합니다. 공급자 인증에는 운영자가 서버에 설정한 키를 사용하며 그 키를 앱에 제공하지 않습니다. 몽글 서버는 AI 요청과 응답 내용을 메모리에서 처리하며, DB와 오브젝트 저장소에 녹음·전사문·프롬프트·AI 결과 내용을 저장하거나 결과 캐시를 만들지 않습니다. 중복 처리 방지에는 요청 식별자와 서버 비밀키로 만든 내용 확인값 등 메타데이터를 사용합니다. 완료된 응답을 다시 내려받을 수 없으므로 응답 유실 후 사용자가 새 처리를 요청하면 사용량이 다시 차감될 수 있습니다. 이 비저장 범위는 몽글의 AI 처리 저장소에 관한 것이며, 아래 선택형 암호화 동기화와 외부 AI 제공자의 정책은 별개입니다. OpenRouter 및 실제 모델 제공업체의 처리·보관에는 각 업체의 개인정보처리방침과 서비스 설정이 적용됩니다.

Plus 사용량과 비용 운영 기록

Plus 서버는 월간 한도, 비용 확인과 운영 오류 진단을 위해 무작위 계정 식별자, 무작위 요청 식별자, 요청 시각, 처리 단계, 모델명, 공급자 요청 식별자, 입력·출력 토큰 수, 음성 길이, 처리 시간, 비용, 성공·실패·취소 상태와 앱 버전을 처리합니다. 이 운영 기록에는 녹음, 전사문, 정리 결과, 프롬프트, 공급자 API 키와 인증 토큰을 넣지 않습니다. 로컬 AI 사용은 수집하지 않습니다.

운영 기록은 관리자 원장이 수신했다는 확인을 받을 때까지 Plus 서버의 재전송 대기열에 남을 수 있습니다. 확인된 기록과 상세 요청 메타데이터는 35일이 지나면 후속 서비스·운영 동기화 요청에서 정리되므로 요청이 없으면 더 오래 남을 수 있으며, 관리자 비용 원장은 현재 운영 정책상 기간 제한 없이 보관합니다. 무작위 계정 식별자를 사용하는 비용 원장은 계정·세션 삭제와 분리해 운영 집계 목적으로 보존합니다.

선택형 암호화 동기화

기기 간 동기화는 AI 처리 방식과 독립된 기능이며 기본으로 꺼져 있습니다. 계정에 로그인하고 별도 보관 동의를 하면 노트, 전사문, 할 일, 활동 이력과 기록 간 연결을 기기에서 암호화한 뒤 서버에 사본을 보관합니다. 원본 음성 동기화는 추가로 켜야 하며 기본으로 꺼져 있습니다. 동기화를 켰다는 이유만으로 이 내용을 AI 제공자에게 보내지 않습니다.

동기화 서버에는 암호문, 암호화된 키 복구 자료, 계정·기기 식별자, 연결 시각, 암호문 크기·확인값, 버전과 삭제 여부 등 전송·복구에 필요한 정보를 보관합니다. 복구 코드와 기록 복호화 키는 서버에 보내지 않습니다. 새 기기나 다시 연결한 기기에서 복구 코드가 필요하며, 코드를 잃으면 운영자가 암호화된 기록을 복구할 수 없습니다.

일시정지하거나 이 기기 연결을 해제해도 기존 서버 사본은 남습니다. 음성 동기화를 끄면 새 음성 업로드를 중단하며 이미 보관한 사본을 자동 삭제하지 않습니다. 서버 사본 삭제는 동기화 설정에서 별도로 요청할 수 있습니다. 삭제를 요청하면 기존 세대와 기기의 접근을 차단한 뒤 암호문을 정리하며, 진행 중 업로드나 저장소 오류가 있으면 정리가 보류되어 재시도가 필요할 수 있습니다. 서버 사본 삭제는 각 기기에 이미 저장된 기록을 삭제하지 않습니다. 연결된 기기에서 기록을 완전히 삭제한 경우에는 동기화로 삭제 상태가 전파됩니다.

3. 저장 위치와 보호

  • 기록 내용, 환경설정과 완료된 원본 음성은 앱 전용 저장소에서 Android Keystore 기반 AES-GCM으로 암호화됩니다.
  • 녹음 중에는 앱이 중단됐을 때 복구하기 위해 평문 PCM 파일을 앱 전용 폴더에 임시 저장합니다. 녹음 완료 후 암호화본을 만들고 임시 파일을 삭제합니다.
  • 음성 재생용 임시 파일은 앱 캐시에 만들며 재생 종료, 화면 이탈 또는 앱 재시작 때 삭제합니다.
  • Android 자동 클라우드 백업과 기기 간 자동 앱 데이터 전송에서는 몽글 데이터를 제외합니다.
  • 이전 앱 버전이 저장한 개인 공급자 키와 관리자 기기 연결 정보는 업그레이드 때 삭제하며 기록·로컬 모델·백업 데이터는 유지합니다.

4. 보관 기간과 삭제

  • 정리가 완료됐고 고정하지 않은 원본 음성은 녹음 시점부터 30일이 지나면 앱의 일일 유지관리 작업에서 자동 삭제됩니다.
  • 고정한 원본 음성과 정리에 실패했거나 대기 중인 원본 음성은 자동 삭제하지 않습니다.
  • 노트, 전사문, 요약과 할 일은 자동 만료되지 않으며 사용자가 완전히 삭제하거나 앱을 제거할 때까지 기기에 남습니다.
  • 휴지통은 자동으로 비우지 않습니다. 앱에서 기록을 완전히 삭제하면 해당 기록과 연결된 원본 음성을 삭제합니다.
  • 다운로드한 AI 모델은 설정에서 개별 삭제하거나 앱을 제거해 삭제할 수 있습니다.

5. 수동 백업과 복원

사용자가 요청하면 몽글은 기록과 남아 있는 원본 음성을 비밀번호로 암호화한 백업 파일로 내보냅니다. 백업은 PBKDF2-HMAC-SHA256으로 만든 키와 AES-256-GCM을 사용하며, 사용자가 Android 시스템 파일 선택기에서 고른 위치에 저장됩니다.

Google Drive 등 외부 저장소를 선택하면 백업 파일의 저장과 보관에는 해당 저장소 사업자의 약관과 개인정보처리방침이 적용됩니다. 몽글 운영자는 백업 파일이나 비밀번호를 받지 않습니다. 앱에서 기록을 삭제해도 외부에 만든 백업 사본은 자동 삭제되지 않으므로 사용자가 저장 위치에서 직접 삭제해야 합니다. 비밀번호를 잃으면 백업을 복구할 수 없습니다.

6. 권한

  • 마이크: 사용자가 시작한 음성 메모를 녹음합니다.
  • 알림: 녹음·정리 상태, 정리 완료와 시간이 지정된 할 일을 알립니다.
  • 알람 및 리마인더: 사용자가 지정한 시각에 로컬 할 일 알림을 예약합니다.
  • 인터넷 및 네트워크 상태: AI 모델을 다운로드하고 Wi-Fi 전용 다운로드 설정을 적용합니다. 계정·구매 확인, 클라우드 전사·정리와 검색, 별도로 켠 암호화 동기화에도 인터넷을 사용합니다.
  • 진동: 녹음 시작·종료와 종료 임박 상태를 알려 줍니다.

마이크와 알림 권한을 허용하지 않아도 직접 노트와 할 일을 작성할 수 있습니다.

7. 계정과 어린이

로컬 기능은 계정 없이 이용할 수 있습니다. 선택형 Plus는 Google 계정의 식별자·이메일·표시 이름을 처리하고 Google Play에서 구독을 관리합니다. 현재 앱은 일반 성인용 개인 생산성 도구로 설계됐으며 어린이를 대상으로 하지 않습니다.

Plus 계정은 앱의 계정 관리에서 삭제할 수 있습니다. 계정과 세션, 상세 요청 기록 및 동기화 서버 사본을 삭제하고, 중복 구매 토큰의 부정 재사용을 방지하는 가명화된 식별자와 위에서 설명한 무작위 계정 식별자의 비용 원장은 보존합니다. 동기화 사본 정리가 진행 중이면 완료될 때까지 계정 삭제를 다시 시도해야 한다고 안내합니다. 기기 안의 노트는 별도로 유지됩니다. 계정을 삭제해도 Google Play 구독의 자동 갱신은 취소되지 않으므로 Google Play에서 별도로 관리해야 합니다. 앱 안의 정보는 휴지통과 완전 삭제 기능으로 사용자가 직접 삭제할 수 있습니다. Hugging Face가 모델 다운로드 과정에서 처리한 네트워크 정보에 관한 요청은 위 Hugging Face 개인정보처리방침의 연락 방법을 이용해야 합니다.

9. 방침 변경

앱의 데이터 처리 방식이 바뀌면 이 방침을 수정하고 시행일을 갱신합니다. 데이터 처리 기능이 변경되면 Google Play 데이터 안전성 정보와 이 방침도 실제 동작에 맞게 갱신합니다.
