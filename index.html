몽글 개인정보처리방침

시행일: 2026년 9월 13일

몽글 - AI 음성 메모·노트·할 일(이하 “몽글”)은 음성을 노트와 할 일로 정리하는 Android 앱입니다. 몽글 계정 없이 사용할 수 있으며 기본은 기기 안에서 음성을 인식하고 글을 정리하는 방식입니다. 사용자가 자신의 OpenRouter API 키를 저장하고 온라인 처리를 켜면 녹음과 전사문을 외부 AI 서비스로 전송합니다. 이 방침은 앱이 처리하는 정보, 외부 통신, 보관 기간과 사용자가 정보를 관리하는 방법을 설명합니다.

1. 앱이 기기에서 처리하는 정보

사용자가 기능을 선택하면 몽글은 다음 정보를 기기 안에서 처리합니다.

  • 마이크로 녹음한 음성
  • 음성에서 만든 전사문, 제목, 요약, 카테고리와 할 일
  • 사용자가 직접 작성하거나 수정한 노트, 할 일, 일정과 자주 쓰는 말
  • 알림, 모델 선택, Wi-Fi 전용 다운로드 등 앱 환경설정
  • 사용자가 입력한 OpenRouter API 키와 온라인 처리·모델 선택 설정

이 내용은 몽글 운영자 서버로 업로드되지 않습니다. 앱에는 회원가입, 광고, 사용 분석, 원격 충돌 보고 기능이 없습니다.

2. AI 모델 다운로드와 외부 통신

사용자가 AI 모델 다운로드를 시작하면 몽글은 HTTPS를 통해 Hugging Face에서 음성 인식과 글 정리에 사용할 여러 AI 모델 파일을 받습니다. 음성, 전사문, 노트, 할 일은 이 요청에 포함하지 않습니다.

인터넷 통신의 특성상 모델 파일 제공자인 Hugging Face는 IP 주소, 요청 시각과 일반적인 네트워크·기기 정보를 받을 수 있습니다. Hugging Face는 서비스 사용 과정에서 IP 주소, 위치, 기기 유형·모델·운영체제 등의 정보를 자동 기록할 수 있다고 안내합니다. 해당 정보의 처리는 Hugging Face 개인정보처리방침을 따릅니다. 모델 다운로드를 건너뛰어도 직접 노트와 할 일을 작성할 수 있습니다.

OpenRouter 온라인 처리는 기본으로 꺼져 있습니다. 사용자가 켜면 녹음은 음성 전사 요청에, 전사문과 분류 목록은 글 정리 요청에 포함되어 HTTPS로 OpenRouter 및 선택한 모델 제공업체에 전송됩니다. API 키는 OpenRouter 요청 인증에 사용되며, 요청에는 IP 주소 등 네트워크 정보가 수반됩니다. 키 확인 버튼은 인증 정보를 조회하며 녹음이나 전사문을 보내거나 모델을 호출하지 않습니다. 실제 전사와 정리는 사용량에 따라 사용자의 OpenRouter 계정에 비용이 발생합니다.

외부 서비스의 정보 보관과 데이터 이용은 OpenRouter 개인정보처리방침, 사용자의 계정 설정 및 실제 모델 제공업체의 정책에 따릅니다. 기기에서의 암호화 저장이 외부 서비스의 무보관을 보장하지는 않습니다. 온라인 모드를 끄거나 키를 삭제하면 이후 온라인 요청을 중단하며, 이미 전송된 정보에 관한 요청은 OpenRouter 및 해당 제공업체에 문의해야 합니다.

3. 저장 위치와 보호

  • 기록 내용, 환경설정과 완료된 원본 음성은 앱 전용 저장소에서 Android Keystore 기반 AES-GCM으로 암호화됩니다.
  • 녹음 중에는 앱이 중단됐을 때 복구하기 위해 평문 PCM 파일을 앱 전용 폴더에 임시 저장합니다. 녹음 완료 후 암호화본을 만들고 임시 파일을 삭제합니다.
  • 음성 재생용 임시 파일은 앱 캐시에 만들며 재생 종료, 화면 이탈 또는 앱 재시작 때 삭제합니다.
  • Android 자동 클라우드 백업과 기기 간 자동 앱 데이터 전송에서는 몽글 데이터를 제외합니다.
  • OpenRouter API 키는 Android Keystore 기반 AES-GCM으로 별도 암호화하며 수동 백업과 자동 기기 전송에 포함하지 않습니다. 키는 설정에서 삭제할 수 있습니다.

4. 보관 기간과 삭제

  • 정리가 완료됐고 고정하지 않은 원본 음성은 녹음 시점부터 30일이 지나면 앱의 일일 유지관리 작업에서 자동 삭제됩니다.
  • 고정한 원본 음성과 정리에 실패했거나 대기 중인 원본 음성은 자동 삭제하지 않습니다.
  • 노트, 전사문, 요약과 할 일은 자동 만료되지 않으며 사용자가 완전히 삭제하거나 앱을 제거할 때까지 기기에 남습니다.
  • 휴지통은 자동으로 비우지 않습니다. 앱에서 기록을 완전히 삭제하면 해당 기록과 연결된 원본 음성을 삭제합니다.
  • 다운로드한 AI 모델은 설정에서 개별 삭제하거나 앱을 제거해 삭제할 수 있습니다.

5. 수동 백업과 복원

사용자가 요청하면 몽글은 기록과 남아 있는 원본 음성을 비밀번호로 암호화한 백업 파일로 내보냅니다. 백업은 PBKDF2-HMAC-SHA256으로 만든 키와 AES-256-GCM을 사용하며, 사용자가 Android 시스템 파일 선택기에서 고른 위치에 저장됩니다.

Google Drive 등 외부 저장소를 선택하면 백업 파일의 저장과 보관에는 해당 저장소 사업자의 약관과 개인정보처리방침이 적용됩니다. 몽글 운영자는 백업 파일이나 비밀번호를 받지 않습니다. 앱에서 기록을 삭제해도 외부에 만든 백업 사본은 자동 삭제되지 않으므로 사용자가 저장 위치에서 직접 삭제해야 합니다. 비밀번호를 잃으면 백업을 복구할 수 없습니다.

6. 권한

  • 마이크: 사용자가 시작한 음성 메모를 녹음합니다.
  • 알림: 녹음·정리 상태, 정리 완료와 시간이 지정된 할 일을 알립니다.
  • 알람 및 리마인더: 사용자가 지정한 시각에 로컬 할 일 알림을 예약합니다.
  • 인터넷 및 네트워크 상태: AI 모델을 다운로드하고 Wi-Fi 전용 다운로드 설정을 적용합니다. 사용자가 OpenRouter 온라인 모드를 켜면 전사·정리 API 요청에도 인터넷을 사용합니다.
  • 진동: 녹음 시작·종료와 종료 임박 상태를 알려 줍니다.

마이크와 알림 권한을 허용하지 않아도 직접 노트와 할 일을 작성할 수 있습니다.

7. 계정과 어린이

몽글은 자체 사용자 계정을 만들지 않으며 이름, 이메일 주소, 전화번호 또는 결제 정보를 요구하지 않습니다. 선택형 온라인 기능에는 사용자가 발급한 OpenRouter API 키가 필요하고 계정·결제는 OpenRouter에서 관리합니다. 현재 앱은 일반 성인용 개인 생산성 도구로 설계됐으며 어린이를 대상으로 하지 않습니다.

몽글 운영자는 계정이나 사용자 콘텐츠를 서버에 보관하지 않습니다. 앱 안의 정보는 휴지통과 완전 삭제 기능으로 사용자가 직접 삭제할 수 있습니다. Hugging Face가 모델 다운로드 과정에서 처리한 네트워크 정보에 관한 요청은 위 Hugging Face 개인정보처리방침의 연락 방법을 이용해야 합니다.

9. 방침 변경

앱의 데이터 처리 방식이 바뀌면 이 방침을 수정하고 시행일을 갱신합니다. 광고, 분석, 계정 또는 클라우드 동기화 기능이 추가되는 경우 Google Play 데이터 안전성 정보와 이 방침도 함께 갱신해야 합니다.
